# Проверка первой версии

Проверено локально на macOS Apple Silicon (Python 3.11):

- [x] Установка проекта в отдельное окружение без MLX.
- [x] 20 автоматических тестов: разбиение длинной записи, отмена,
  загрузка/кэш модели, UTF-8, защита от перезаписи, очистка временных файлов.
- [x] Настоящий FFmpeg: конвертация файла с кириллицей и пробелами в пути.
- [x] Настоящая GigaAM Q8_0: русская синтезированная речь распознана на CPU,
  полный путь от входного аудио до TXT работает.
- [x] Повторная транскрипция при `HF_HUB_OFFLINE=1` с моделью из кэша.
- [x] Создание окна Tkinter.
- [x] Упаковка настоящего `.app` для macOS с собственной LGPL-сборкой FFmpeg.
- [x] Полная транскрипция тестовой фразы и открытие/закрытие GUI внутри `.app`.

Windows x64 и macOS Intel проверяются облачным workflow
`.github/workflows/build.yml`. Он также повторяет проверку macOS arm64
на чистом GitHub runner. Для каждого ZIP проверяются настоящее распознавание,
GUI и повторный запуск при `HF_HUB_OFFLINE=1`. Статус конкретного релиза
определяется успешным запуском этого workflow, а не наличием этого файла.
