Минимальный локальный транскрибатор русской речи: transcribe.cpp + GigaAM на CPU.

## Какой архив скачать

- **Windows 10/11, Intel/AMD 64 бит:** `MiniTranscriber-windows-x64.zip`.
  Распакуйте всю папку и запустите `MiniTranscriber.exe`. Python не нужен.
- **Mac с M1/M2/M3/M4/M5:** `MiniTranscriber-macos-arm64.zip`.
- **Mac с процессором Intel:** `MiniTranscriber-macos-x64.zip`.
  Распакуйте архив и переместите `MiniTranscriber.app` в «Программы».
  Сборки macOS проверяются на macOS 14 (Apple Silicon) и macOS 15 (Intel).

Выберите аудио или видео → «Расшифровать» → TXT рядом с записью.
При первом распознавании потребуется интернет: скачивается модель (~272 МБ).
Далее работает локально, без отправки аудио в облако.

## Первый запуск неподписанного приложения

Сборки не имеют подписи коммерческого разработчика. Windows может показать
SmartScreen. Проверьте, что архив получен из этого репозитория, перед запуском.
На macOS при блокировке откройте «Системные настройки → Конфиденциальность
и безопасность → Всё равно открыть», затем подтвердите запуск. Эта возможность
может быть недоступна на управляемых рабочих компьютерах. Не отключайте
Gatekeeper/антивирус глобально. Для распространения без предупреждений нужна
Developer ID-подпись и notarization Apple / подходящая Windows-подпись.

## Проверки и ограничения

Для каждого архива CI запускает автоматические тесты и **само собранное
приложение**: FFmpeg, загрузку модели, настоящее распознавание русской речи
на CPU, сохранение UTF-8 по пути с кириллицей и открытие/закрытие окна.
Это не заменяет проверку всех кодеков и всех версий ОС на компьютере получателя.

Без микрофона, разделения по спикерам и таймкодов. Длинные записи обрабатываются
по 25 секунд; слова на границах могут распознаваться хуже. Для временного WAV
нужно примерно 115 МБ на час записи.

В архиве — собственная LGPL-сборка FFmpeg без GPL/nonfree-компонентов и её
точные исходники, лицензия и рецепт сборки. См. `THIRD_PARTY.md` внутри приложения.
Модель скачивается отдельно и не включена в архив.
